SISTEMA DE GESTIÓN DE PAÍSES 
Descripción:

El programa presentado fue realizado en python y permite manipular información de paises almacenada en un archivo.csv

La aplicación utiliza listas, diccionarios, funciones y archivos CSV para gestionar los datos, 
permitiendo realizar operaciones de consulta, filtrado, ordenamiento y generación de estadísticas.

FUNCIONALIDADES: 
.Mostrar todos los paises registrados
.Buscar algun pais que se encuentre registrado por su nombre 
.Modificar un pais que se encuentra cargado
.Agregar nuevos paises 
.Filtrar paises por su continente,poblacion o superficie
.Ordenar países por nombre, población o superficie
.Mostrar estadisticas de los paises 
.Los cambios realizados se guardan automaticamente en el archivo.csv
